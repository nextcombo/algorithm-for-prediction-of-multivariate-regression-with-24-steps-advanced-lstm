# Algorithm for Prediction of Multivariate Regression with 24 Steps Advanced LSTM-Attention in the First Zone of the Chinese Academy of Sciences, KOA-CNN-LSTM-Attention

Program Platform: Suitable for MATLAB 2023 and above versions.
Code Explanation: This algorithm is based on the Kepler Optimization Algorithm (KOA), Convolutional Neural Networks (CNN), and Long Short-Term Memory Networks (LSTM) to fuse multi-head attention mechanisms for advanced 24-step multivariate time series regression prediction.
The Kepler Optimization Algorithm (KOA) was proposed by Mohamed Abdel-Basset et al. in 2023, inspired by the laws of celestial mechanics. It was published in the top journal "Knowledge-Based Systems" in May 2023, which is a scientific journal at the first level of the Chinese Academy of Sciences. KOA is inspired by the laws of Kepler's planetary motion and can predict the position and velocity of any given planet at any given time. In KOA, each planet and its position are considered as a candidate solution, which is randomly updated during the optimization process relative to the best solution so far.
We utilized this newly developed algorithm to optimize the hyperparameters in our CNN-LSTM-Attention time-series and spatial feature combination-fusion attention mechanism regression prediction program code, forming the KOA-CNN-LSTM-Attention multivariate regression prediction model.
Functions:
1. Multivariate feature input with single sequence variable output, inputting features from the previous day to make predictions for the next day, achieving 24-step predictive forecasting.
2. Optimizing learning rates, convolution kernel sizes, and number of neurons three key parameters through the Kepler Optimization Algorithm, aiming to minimize MAPES.
3. Providing loss, RMSE iterative change polar coordinates graph; network feature visualization graph; test comparison graph; fitness curve.
4. Providing calculation results such as MAPES, RMSE, MAE etc.
Applicable fields:
Wind speed prediction, photovoltaic power prediction, power generation power prediction, carbon price prediction, and other applications.
Data format: 18 meteorological features per day, sampling time is 24 hours, output is the power output of 24 hours for the next day, which means 18×24 input and 1×24 output, there are a total of 75 such samples.
